# [빨모쌤 영어공부하기!] 기획서

## 1. 프로젝트 개요
- 프로젝트명: 빨모쌤과 함께하는 영어공부
- 프로젝트 목표: 영어공부하기
- 사용 상황: 모바일 웹으로 사용할 예정
- 데이터 활용 : Notion 데이터
  (notion api key: .env 파일에 NOTION_API_KEY로 별도 관리, git에는 올리지 않음)

## 2. 핵심 기능
- 필수 기능:  notion에 올라온 영어 표현들을 연습하게 도와주는 모바일 친화적 웹앱
- 페이지 구성: 
   - (날짜선택) 데이터베이스에 올라와 있는 날짜선택하면 해당 데이터를 학습하게 해줌.
    1) URL을 누르면 바로 해당 유튜브로 갈 수 있게 해줌.
    2) Study 날에 내가 공부한 날짜를 YY/MM/DD로 표시해줌
 - (✔️학습 키워드 버튼): 학습키워드에서 학습을 위해 정리되어 있는 영어가 순차적으로 나옴.
   대화의 형식이면 대화가 연달아 나오면서 읽어주고, 그 시간만큼 따라 연습할 수 있게 해줌.
   한국어와 영어가 동시에 나오되, 한국어 on/off기능이 나옴.
   1) 속도 버튼이 있어야함 0.5배속~2배속
   2) 탭한번을 누르면 기본적으로 다음 문장으로 넘어감
   3) 이동버튼이 있어서 앞뒤로 이동도 가능하고, 목차보기 버튼으로 한눈에 문장들이 정리되어 해당 문장으로 넘어가게 해줌
 - (✔️연습하기 버튼) :  페이지에 있는 ✔️한글 과 ✔️영어를 한눈에 볼 수 있게 해준다.
   1) 해당 문장을 누르면 읽어줌.
 -  (✔️ 나만의 문장) 영어가 순차적으로 나옴. 학습키워드와 똑같은 UI를 가지고, 내용도 동일
[Notion 경로 :  home>영어노트> 유튜브database ]

 - (책공부하기) 빨모쌤의 라이브 영어회화
   1) UNIT 16. ~ UNIT 75까지 목차를 놓고 누르면 그 하단에 있는 내용들을 공부할 수 있게 하기
   2) UNIT 을 들어가면 순차적으로 표현을 연습하게 하기
      탭을 누르면 다음 문장으로 넘어가게 하기. 한글, 영어 on/off기능 포함하기
      bold로 표시되어 있는 것들에 대해서도 그대로 표현하기
[Notion 경로: home>책내용상세정리>빨모쌤의 라이브영어회화]


## 3. 기술 스택
- 개발 언어: Python 3
- 웹 프레임워크: Flask (Jinja2 템플릿)
- 프론트엔드: HTML, CSS, JavaScript
- 데이터 저장: JSON 파일 (data/파일명.json)
- 포트: 5000 (충돌 시 5001)
